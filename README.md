# SSIKPPANG! — 식빵!

가상의 만화 캐릭터와 즐기는 짧은 브라우저 게임입니다. 마이크의 상대 음량 또는 마우스 클릭·휴대폰 터치 횟수로 점수를 올립니다.

## 실행하기

별도의 패키지 설치나 빌드가 필요 없는 HTML/CSS/JavaScript 프로젝트입니다.

```sh
python3 -m http.server 4173 --directory dist
```

브라우저에서 `http://localhost:4173`을 엽니다. 마이크 모드는 HTTPS 또는 localhost와 브라우저의 마이크 권한이 필요합니다. 휴대폰은 HTTPS로 배포한 주소에서 확인하세요.

## 게임 기능

- 기본 모드: 발음 검사 없이 3초 동안 마이크 상대 음량 측정
- 손가락 모드: 첫 클릭·터치부터 5초 동안 입력 횟수 측정, 1회 = 1점
- 목소리 모드 최고 10,000점, 손가락 모드 20·40·60·80회 초과 시 반응 상승
- 선택한 대상 하나만 표시하고, 클릭하면 13종 캐릭터 중 선택
- 한국어 대표 외침: 식빵! / SSIKPPANG!
- 언어·모드별 브라우저 내 기록, 닉네임 저장과 기록 삭제
- 플레이 중단·Escape 키·화면 이동 시 취소
- 움직임 줄이기 설정 및 키보드 입력 지원

음성 파일을 녹음하거나 음성 인식 서버에 보내지 않습니다. 기록은 현재 브라우저에 저장하며 공개 온라인 순위가 아닙니다. 상대 음량(dBFS)은 실제 환경 데시벨(dB SPL)이 아닙니다.

## 파일 구성

```text
dist/
  index.html        게임 화면
  app.js            게임 로직·측정·점수·로컬 기록
  style.css         손글씨 디자인·반응 애니메이션
  docs.css          안내 페이지 스타일
  guide.html        플레이 안내
  scoring.html      점수 계산과 반응 단계
  about.html        게임 소개
  privacy.html      현재 데이터 처리 안내
  robots.txt
  sitemap.xml
  assets/           캐릭터 이미지와 폰트·폰트 라이선스
ADSENSE-READINESS.md 수익화 준비 현황과 미완료 항목
```

## 배포 전 확인

`dist` 폴더를 정적 웹사이트의 공개 루트로 사용합니다. `sitemap.xml`과 `robots.txt`의 주소는 실제 운영 도메인에 맞춰 바꾸세요. 운영자 정보와 문의 채널, 광고 기능을 도입할 경우 개인정보·동의 안내를 실제 운영 내용에 맞게 갱신해야 합니다. AdSense 연결 코드와 ads.txt를 포함합니다. 자동 광고와 필요한 동의 메시지는 AdSense 계정에서 설정하세요. 별도 방문 분석 코드는 없습니다. AdSense 승인은 보장되지 않습니다.

Sites 전용 배포 식별자, 인증 정보, 로컬 백업과 Git 내부 정보는 이 저장소에 포함하지 않았습니다.

## 폰트와 삽화

나눔손글씨 펜(Nanum Pen Script)은 SIL Open Font License 1.1에 따라 사용하며, 라이선스 원문은 `dist/assets/fonts/OFL-NanumPenScript.txt`에 포함되어 있습니다. 캐릭터 삽화와 게임 코드 제작에 AI 도구를 사용했습니다. 게임 전체에 적용할 별도의 오픈소스 라이선스는 아직 지정하지 않았습니다.

본문 폰트: Noto Sans KR (OFL), 강조 문구: Nanum Pen Script (OFL). 배구 스파이크 로고와 가상의 캐릭터 일러스트를 포함합니다. 손가락 효과음은 운영자가 제공한 acoustic snare MP3를 같은 사이트에서 재생합니다.
